Dante has work for you in Port Solano, an original top-down crime game set in a coastal city. Walk or drive through six districts, dodge police, collect hidden packages, or earn cash behind the wheel of a taxi. The game runs offline and keeps your progress and sound setting in your browser.

## Play locally

Run `node serve.ts` and open [http://localhost:8080](http://localhost:8080). The game needs no build step.

## Controls

| Input | Action |
| --- | --- |
| Enter or Space | Continue from the title or results screen |
| N | Start a new story from the title |
| WASD or arrows | Walk, steer, accelerate, or reverse |
| Shift | Sprint |
| E | Enter or exit a car |
| Space | Handbrake |
| F | Melee attack |
| Mouse and left click | Aim and fire |
| P or Escape | Pause or resume |
| R | Retry from pause or results |
| Q | Save and return to the title from pause |
| M | Toggle sound |

## Dante's story

1. First Wheels
2. The Package
3. Getaway Driver
4. Taxi Trouble
5. Rooftop Deal
6. The Big Score

After the finale, keep exploring, take repeat fares, or hunt for the ten hidden packages.
